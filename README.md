# Zack's Mohawk Limited
## QuickFind

## Overview

Command line tool for quickly finding files by name, or text within files.

## How To Install

	npm install

## How To Configure

No configuration required.

## How To Setup Command Line Alias

To be able to run QuickFind from any folder on Mac, run the following setup script.

	./setup_mac.sh

For Linux machines, run the following setup script.

	./setup_linux.sh

## How To Run

From any location, type the following:

	quickfind
